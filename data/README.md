# Data

This project uses the 'IBM HR Analytics Employee Attrition & Performance' dataset.

1. Download it from Kaggle:
   https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
2. Place `WA_Fn-UseC_-HR-Employee-Attrition.csv` in this folder.

The CSV is not included in this repo. Please get it from the original source.
